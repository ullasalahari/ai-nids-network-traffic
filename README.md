# AI-Based Network Intrusion Detection System

This project uses Machine Learning (Random Forest) to detect malicious network traffic.

 Features
- Dataset Preview
- Data Visualization
- Random Forest Training
- Confusion Matrix
- Feature Importance
- Live Prediction
- Streamlit Dashboard

## Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
